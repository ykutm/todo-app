# Todo App

## 概要

ローカルストレージ対応のToDoリストアプリです。

## 機能

- タスクの追加・削除
- 完了/未完了の切り替え
- フィルター機能（すべて/未完了/完了）
- ページをリロードしてもタスクが保持される

## 使用技術

- HTML
- CSS
- JavaScript（バニラJS）
- localStorage

## 学び

- 三項演算子の使い方
- localStrageへのデータ保存（JSONのデータ変換）
- datesetカスタムデータ属性
- DOM操作（テンプレートリテラル）、クラス名操作
- 引数（addEventListenerのイベントオブジェクト、forEach）
- 日本語入力対応（入力変換確定後にタスク追加）
